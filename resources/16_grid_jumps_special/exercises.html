Module 16 — Exercises

Five hands-on exercises on synthetic GBM-on-grid data.

← module README · extract

Exercise 1 — Generate synthetic GBM-on-grid easy · 30 min

Write code/synthetic_gbm.py (in your code/ directory) that:

  1. Simulates a GBM: S_t = S_0 × exp((μ - σ²/2) t + σ W_t).
  2. Projects onto a grid: D_t = round(S_t / g) × g.
  3. Returns both S (true) and D (displayed) for t = 0, 1, ..., 1000.

Plot both. Verify the display is a step function and the true price is smooth.

Exercise 2 — Smooth and visualize 30 min

Use code/smooth.py on the synthetic data from Exercise 1. Try α ∈ {0.05, 0.1, 0.3, 0.5}.

Plot the true price, the display, and the smoothed estimate overlaid. Identify the lag — how many ticks does the smoother trail the true price?

Question: which α has the smallest lag? Which is the most stable?

Exercise 3 — Jump signal accuracy 1 hour

On the synthetic data, run the jump signal from code/jump_signal.py. Compare the signal's predicted next display to the actual next display.

Compute accuracy: what fraction of signals are correct? What's the average error of the predicted next display?

Exercise 4 — Backtest the strategy 1.5 hours

Use code/grid_strategy.py on the synthetic data. Track PnL.

Decompose PnL: how much came from grid-jump alpha vs noise?

Question: is the strategy profitable on synthetic GBM-on-grid data? If not, what parameter is wrong?

Exercise 5 — α sweep 2 hours

For α ∈ {0.02, 0.05, 0.1, 0.2, 0.3, 0.5, 0.7}, run the backtest and record:

  • Total PnL
  • Sharpe ratio
  • Number of trades
  • Win rate

Plot each metric vs α. Find the optimal α.

Question: does the optimal α depend on the GBM's σ? (Test with σ = 0.001, 0.01, 0.05.)
