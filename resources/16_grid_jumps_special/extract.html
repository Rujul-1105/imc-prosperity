The setup

The true price $S_t$ follows a geometric Brownian motion:

$dS_t = \sigma S_t \, dW_t$

Equivalently, in discrete time at step $\Delta t$:

$\log S_{t+1} = \log S_t + \sigma \sqrt{\Delta t} \cdot \varepsilon_t$,   $\varepsilon_t \sim \mathcal{N}(0, 1)$

The exchange displays the grid-projected price:

$D_t = \text{round}(S_t / g) \cdot g$

where $g$ is the grid size (e.g., 1.0 for integer prices, 0.1 for one-decimal prices, etc.). The display is a piecewise-constant function of the true price.

The grid jump

Between ticks $t$ and $t+1$, the display changes by $D_{t+1} - D_t$. This change is either 0 (the true price stayed in the same grid cell) or $\pm g$ (a jump up or down by one grid unit). Jumps of more than $g$ are also possible if the true price moves very fast.

The expected size of the true-price change over one tick is $\sigma \sqrt{\Delta t} \cdot S_t$. The probability of a jump in either direction is roughly:

$\Pr(\text{jump}) \approx 2 \cdot \Phi\!\left(-\frac{g/2}{\sigma S_t \sqrt{\Delta t}}\right)$

where $\Phi$ is the standard normal CDF. For small $\sigma S_t \sqrt{\Delta t}$ relative to $g$, this is high. For large, low.

Estimating the true price

We observe $D_t$ but want to estimate $S_t$. The simplest estimator is the exponential moving average (EMA):

$\hat{S}_t = \alpha \cdot D_t + (1 - \alpha) \cdot \hat{S}_{t-1}$

$\alpha$ is the smoothing factor. Small $\alpha$ (e.g., 0.05) means slow adaptation, smoother estimate, more lag. Large $\alpha$ (e.g., 0.5) means fast adaptation, noisier estimate, less lag.

The optimal $\alpha$ depends on the ratio of grid size to true-price volatility. Roughly, $\alpha \approx g / (\sigma S \sqrt{\Delta t})$.

A more sophisticated estimator is the Kalman filter, which models the difference between $S_t$ and $D_t$ explicitly. The Kalman update:

$\hat{S}_{t|t} = \hat{S}_{t|t-1} + K_t (D_t - \hat{S}_{t|t-1})$

where $K_t$ is the Kalman gain, computed from the prior uncertainty and the observation noise. The Kalman is what you'd use in production; EMA is fine for the curriculum.

The jump signal

Given the smoothed estimate $\hat{S}_t$, the expected next display is:

$\hat{D}_{t+1} = \text{round}(\hat{S}_t / g) \cdot g$

The signal:

$\text{signal} = \hat{D}_{t+1} - D_t$

If signal = +g: the display is 1 grid below where it should be. Buy.

If signal = −g: the display is 1 grid above. Sell.

If signal = 0: no edge.

The trade

On signal = +g, place a market buy at the touch (or a limit at $D_t + 1$ for a better fill). On signal = −g, market sell at the touch.

Position sizing: simple rule — fixed position per signal (e.g., 1 unit per signal). Or linear in the magnitude of the deviation (more deviation = bigger bet).

Profit per trade: 1 grid size (after fees).

Holding period: typically 1 tick (you buy at $D_t$, the display jumps to $D_{t+1} = D_t + g$ next tick, you sell at the new display).

Code: EMA smoother

def ema_smoother(displays, alpha=0.1):
    """
    Smooth a sequence of grid-projected display prices via EMA.
    Returns a list of smoothed estimates.
    """
    smoothed = []
    s = displays[0]
    for d in displays:
        s = alpha * d + (1 - alpha) * s
        smoothed.append(s)
    return smoothed

Code: jump signal

def grid_jump_signal(display_now, smoothed, grid_size=1.0):
    """
    Given the current display and the smoothed estimate, return the signal.
    Returns: 'buy' / 'sell' / None
    """
    expected_next = round(smoothed / grid_size) * grid_size
    diff = expected_next - display_now
    if diff >= grid_size * 0.5:
        return "buy"
    elif diff <= -grid_size * 0.5:
        return "sell"
    return None

The full strategy

def grid_jump_strategy(displays, grid_size=1.0, alpha=0.1, max_pos=20):
    """
    For each tick, run the smoother and emit a signal.
    """
    smoothed = ema_smoother(displays, alpha=alpha)
    orders = []
    for t in range(len(displays)):
        signal = grid_jump_signal(displays[t], smoothed[t], grid_size=grid_size)
        if signal == "buy":
            orders.append(("buy", displays[t] + 1, 1))   # limit 1 tick above
        elif signal == "sell":
            orders.append(("sell", displays[t] - 1, 1))  # limit 1 tick below
    return orders

Tuning α

The EMA smoothing factor $\alpha$ is the most important parameter. Sweep over $\{0.05, 0.1, 0.2, 0.3, 0.5\}$ and pick the one with the highest Sharpe.

  • Small α (0.05): slow adaptation, robust to noise, but lags. Best when the true price moves slowly.
  • Large α (0.5): fast adaptation, but jumps can fool the smoother into the wrong direction.

Failure modes

  • Regime change: if the true price switches from a slow regime to a fast regime, the smoother lags and signals are stale. Re-tune α per regime.
  • Non-GBM dynamics: if the underlying isn't GBM (e.g., mean-reverting, trending), the smoother mispredicts. The grid-jump edge is for GBM specifically.
  • Other informed traders: if other teams trade on the same signal, the edge competes away. The first mover has the most profit.
  • Fees eat the edge: if the round-trip fee is more than the grid size, the strategy loses. Verify fees first.
