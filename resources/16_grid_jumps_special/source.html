This module has no canonical paper. The alpha is in the round spec, not a textbook.

Main source

Leo Hawking's P4 retrospective, github.com/Leo-Hawking/IMC-Prosperity-4-Review.

The richest public post-mortem on this edge. Read the section on P4 R5. There's no formal paper because the alpha is specific to the Prosperity round structure.

Supplement 1 — Kalman filter primer

If you want a more sophisticated estimator than EMA, the Kalman filter is the standard. The Wikipedia article is a good starting point: en.wikipedia.org/wiki/Kalman_filter. The "filterpy" Python library has a clean implementation.

Supplement 2 — Discretization of continuous processes

Any numerical methods textbook (e.g., Glasser's Numerical Analysis of Stochastic Differential Equations) covers the discretization of SDEs onto grids. The grid-jump edge is a direct consequence of this discretization.
