How this curriculum works

Every module ships five files following one strict pattern:

  1. README.html — 1-page summary: what, why, where it shows in Prosperity.
  2. explain.html — plain-English explanation. No math, no jargon, no citations. Imagine explaining to a smart friend who's never taken a finance class.
  3. source.html — points to ONE canonical book/paper (chapter, page, link) plus 1–2 supplements. We don't reinvent wheels — we extract from the best.
  4. extract.html — formulas re-derived, code re-implemented, key diagrams re-described in our words. The file you actually do the math from.
  5. exercises.html — 3–5 Python exercises, each one replicating a known winning pattern from P3/P4. Done by running the scripts in code/.
The optimal learning loop: Read explain.html until you can describe the concept in plain words. Glance at source.html to know where it comes from. Use extract.html to actually do the math or write the code. Run the exercises in code/. Repeat weekly.

Prerequisites

Before week 1 you should be comfortable with:

  • Python: lists, dicts, classes, NumPy arrays, pandas DataFrames. If shaky, do NumPy's quickstart and a Kaggle pandas micro-course.
  • Linear algebra: vectors, matrices, dot products. MIT 18.06 lectures 1–10 cover everything you need.
  • Probability: random variables, expectation, variance, normal distribution, conditional probability. MIT 6.041 lectures 1–8.
  • Calculus: derivatives, partial derivatives, gradients. Most market-making math uses nothing beyond ∂.

If you want a single book: Heard on the Street by Leo Boukamp (quant interview puzzles, builds intuition for the kind of thinking Prosperity tests). Not required, but useful.

File format

Every note is a standalone HTML file. They open in any browser, render with inline CSS, and pull only two CDN scripts:

  • MathJax 3 for equations (delivered from jsdelivr).
  • Prism.js for code-block syntax highlighting.

HTML is lighter than PDF for our use case (plain text, formulas, snippets) and easier to edit. We never embed binary blobs. Each file is self-contained except for the two CDNs above.

How to use this folder

  1. Week 1: read the glossary and skim the first case study. Spend 4 hours setting up Python (venv, install numpy/pandas/statsmodels/scikit-learn).
  2. Every week: open weekly_plan.html for that week's reading and deliverable. Work the module's explain → source → extract → exercises loop. Commit each finished module to git.
  3. When Prosperity drops: stop the curriculum. Move to code/. The visualizer and backtester (built separately) plug into this folder's code/ directories in each module.

What this folder is NOT

  • Not a backtester. Exercises use pure-Python toy loops.
  • Not a visualizer. Build that separately when ready.
  • Not a submission template. code/ for that arrives with the competition.
  • Not interview prep. Add a separate 21_interview_prep/ if you want Jane Street puzzles / Citadel questions / Optiver challenges.
