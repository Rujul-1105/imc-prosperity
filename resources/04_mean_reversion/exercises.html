Module 04 — Exercises

Five hands-on exercises. Use the code in code/ as your starting point.

← module README · extract

All exercises use the P3/P4 CSVs you have. STARFRUIT data is in ../prosperity-4/data_capsule/ for the rounds that include it.

Exercise 1 — Fit AR(1) on STARFRUIT easy · 1 hour

Use code/fit_ar1.py to fit AR(1) on P3/P4 STARFRUIT data (day -1 or day 0).

Report the parameters: c, β, σ_ε, μ, σ_p, half-life.

Question: is β between 0 and 1? If so, the series is mean-reverting. If β > 1, explosive. If β ≤ 0, anti-persistent. If β = 1, random walk.

Exercise 2 — Compare AR(1) and OU fits 1 hour

Fit both AR(1) (using statsmodels.AutoReg) and OU (using OLS on Δp vs p) on the same data.

Verify they give similar half-lives. They should — they're approximations of the same underlying process.

Exercise 3 — Rolling z-score and signal 1.5 hours

Implement a rolling z-score in code/zscore_strategy.py:

  1. For each tick $t$ (after a 200-tick warm-up), use the past 200 prices to fit AR(1) and compute $z$.
  2. Plot the z-score time series.
  3. Show the trade entry/exit points (z > 2: sell; z < -2: buy; |z| < 0.5: close).

Verify: the z-score oscillates around 0 and crosses the entry threshold periodically.

Exercise 4 — Backtest the z-score strategy 1.5 hours

Backtest the strategy on P3/P4 STARFRUIT day 0:

  • Entry at |z| > 2, exit at |z| < 0.5, max position 20, fill at touch.
  • Decompose PnL into spread capture + inventory drift.
  • Compute Sharpe ratio per tick.

Question: is the strategy profitable? What fraction of trades are winners? What's the average holding period?

Exercise 5 — Sweep entry thresholds 2 hours

For entry threshold $\tau \in \{0.5, 1.0, 1.5, 2.0, 2.5, 3.0\}$, run the backtest and record:

  • Total PnL
  • Sharpe ratio
  • Number of trades
  • Average holding period
  • Max drawdown

Plot each metric vs $\tau$. The peak of the Sharpe curve is the optimal $\tau$ for this dataset.

Question: is the optimal $\tau$ the one that maximizes PnL, or Sharpe, or something else? What's the trade-off between more trades and bigger bets?
