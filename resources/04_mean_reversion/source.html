Module 04 — Sources

The book, the library, and the docs.

← module README

Main source

Ernie Chan, Algorithmic Trading (2013), Chapter 4: "Mean Reversion."

The clearest practical treatment of mean reversion for trading. Read Ch 4 cover-to-cover. Ch 5 (cointegration) is for module 05.

Where to get it:

  • Print ~$50.
  • Library.
  • Key chapters excerpted online (Google "Chan Algorithmic Trading Ch 4 mean reversion").

Supplement 1 — statsmodels AR(p) documentation

statsmodels AutoReg — the Python function for fitting an AR(p) model. The API is straightforward; the trick is choosing p (= 1 for our purposes) and handling non-stationarity.

Supplement 2 — Hamilton, Time Series Analysis (1994)

Hamilton is the standard academic reference. Ch 3 (ARMA models), Ch 4 (forecasting), Ch 5 (maximum likelihood estimation). Use as a reference, not a first read.

Where to get it: library. PDF copies circulate online.

Supplement 3 — Ornstein–Uhlenbeck primer

The OU process is the continuous-time limit of AR(1). Wikipedia has a clean intro: en.wikipedia.org/wiki/Ornstein–Uhlenbeck_process. Also: any stochastic calculus textbook (Shreve, Ch 3).

What this module does NOT cover (and where to look)

  • Cointegration — module 05.
  • Bayesian mean reversion — module 11.
  • Regime-switching models (Markov-switching) — module 18 (advanced).
  • Mean reversion with state-space models (Kalman filter) — module 10 supplement, advanced.

Reading time budget

  • Chan Ch 4: 4 hours.
  • statsmodels AR docs: 1 hour.
  • Wikipedia OU: 30 minutes.
  • Total: ~5.5 hours. Spread over the week.

Once you've read these, move to extract.html for the formulas and code.
