The five primitives

QuantitySymbolFormulaNotes
Best bid$p^b$$\max\{p : (p,v) \in \text{bids}\}$Highest price any buyer will pay.
Best ask$p^a$$\min\{p : (p,v) \in \text{asks}\}$Lowest price any seller will accept.
Mid price$p^m$$(p^b + p^a) / 2$First fair-value estimate.
Spread$s$$p^a - p^b$Always positive; market-maker's gross revenue.
Microprice$p^\mu$$(v^b \cdot p^a + v^a \cdot p^b) / (v^b + v^a)$Better fair-value when one side is much deeper.

Here $v^b$ is the volume at the best bid and $v^a$ is the volume at the best ask. Both come from state.order_depths[product] in Prosperity.

Depth and the book

The order book $B$ is a pair of sorted lists:

$B = (\text{bids}, \text{asks})$ where
$\text{bids} = [(p_1^b, v_1^b), (p_2^b, v_2^b), \ldots]$ with $p_1^b > p_2^b > \ldots$
$\text{asks} = [(p_1^a, v_1^a), (p_2^a, v_2^a), \ldots]$ with $p_1^a < p_2^a < \ldots$

Cumulative depth $D^b(k)$ = total volume in the first $k$ bid levels. Useful for sizing your market order so you don't exceed available liquidity:

$D^b(k) = \sum_{i=1}^{k} v_i^b$

To buy $Q$ units at the ask without moving the price more than $k$ levels, check $Q \le D^a(k)$.

The matching engine (simplified)

Prosperity's matching engine is FIFO with one twist: no queue priority. When a market order comes in:

  1. Walk the book on the opposite side, best price first.
  2. Fill at the best available price up to the order size.
  3. Continue to the next level if size exceeds depth at the best price.
  4. For a limit order: if it crosses the spread, fill against the opposite side (same as market for the crossing portion). Otherwise, rest on the book.

The "no queue priority" rule means: if 10 people all bid at $p^b$, the 11th person bidding one tick better is matched first, even though they submitted later. This is the source of the "1-tick-better" alpha.

Fill probability (Harris Ch 14)

For a limit order at price $p$ when the mid is $p^m$ and the spread is $s$, the fill probability in the next tick is roughly:

$\Pr(\text{fill}) \approx \begin{cases} 0 & \text{if } p \text{ is not on the touched side} \\ 1 & \text{if } p \text{ is the best level and queue is empty} \\ \text{decreasing} & \text{in queue size and distance from touch} \end{cases}$

For Prosperity specifically, the fill probability is higher than classical markets because of no queue priority — even being slightly better than best bid/ask gives a near-certain fill.

Realized spread and effective spread

After a fill at price $p_f$, your realized spread over the next $T$ ticks is:

$\text{realized spread} = 2 \cdot \text{sign} \cdot (p_f - p^m_T)$

where $\text{sign} = +1$ for a buy and $-1$ for a sell, and $p^m_T$ is the mid $T$ ticks later. This tells you how much of the spread you actually kept after adverse selection.

Effective spread is what you paid/received vs the mid at the moment of fill:

$\text{effective spread} = 2 \cdot \text{sign} \cdot (p_f - p^m_0)$

Effective spread = nominal spread when you fill at touch. Realized spread shrinks with $T$ as the market re-prices against you. The shrinkage is adverse selection.

Adverse selection in one line

$\text{adverse selection cost} = \text{effective spread} - \text{realized spread (after } T \text{ ticks)}$

For a market-maker, the goal is to keep this small. Wider quotes when volatility is high → more spread revenue per fill → more cushion against adverse selection. This is the intuition behind Avellaneda–Stoikov (module 03).

Code: toy order book

Drop this into code/order_book.py and extend. Full version is in that file.

class OrderBook:
    """Toy order book with bid/ask sorted lists."""

    def __init__(self, bids=None, asks=None):
        # bids: list of (price, volume) sorted DESC by price
        # asks: list of (price, volume) sorted ASC by price
        self.bids = sorted(bids or [], key=lambda x: -x[0])
        self.asks = sorted(asks or [], key=lambda x: x[0])

    @property
    def best_bid(self):
        return self.bids[0][0] if self.bids else None

    @property
    def best_ask(self):
        return self.asks[0][0] if self.asks else None

    @property
    def bid_volume(self):
        return self.bids[0][1] if self.bids else 0

    @property
    def ask_volume(self):
        return self.asks[0][1] if self.asks else 0

    @property
    def mid(self):
        bb, ba = self.best_bid, self.best_ask
        return (bb + ba) / 2 if bb is not None and ba is not None else None

    @property
    def spread(self):
        bb, ba = self.best_bid, self.best_ask
        return (ba - bb) if bb is not None and ba is not None else None

    @property
    def microprice(self):
        bb, ba = self.best_bid, self.best_ask
        vb, va = self.bid_volume, self.ask_volume
        if bb is None or ba is None:
            return None
        return (vb * ba + va * bb) / (vb + va)

    def cum_depth(self, side, levels):
        """Cumulative volume in the top N levels of one side."""
        book = self.bids if side == "bid" else self.asks
        return sum(v for _, v in book[:levels])

    def __repr__(self):
        return f"OrderBook(bid={self.best_bid}/{self.bid_volume}, ask={self.best_ask}/{self.ask_volume}, spread={self.spread})"
