Module 02 — Microstructure

Order book mechanics. The vocabulary every later module assumes.

← curriculum home

What you'll know after this module: What bid, ask, mid, spread, depth, microprice, and queue priority are. How an exchange's matching engine turns your order into a fill or a rest. Why a "1-tick better quote" is sometimes all the edge you need. How to parse a Prosperity order-book CSV and compute everything above in pure Python.

Why this module comes first

Every later module — market making, mean reversion, basket arb, options — assumes you can read an order book fluently. Skipping it is how teams lose money on definitions.

Files in this module

explain.html — plain-English tour of an order book. source.html — Larry Harris Ch 1–7, BIS microstructure paper. extract.html — formulas and code re-derived in our notation. exercises.html — 5 hands-on exercises on P3 data. code/order_book.py — toy order book you can extend.

Where this shows up in Prosperity

  • Every round: AMETHYSTS, STARFRUIT, ASH, GIFT_BASKET, ORCHIDS, MACARONS, ROOT — all are quoted via an L3 (price, volume) book. You read this in state.order_depths[product].
  • Your Trader.run(state) method is called per tick with the latest book snapshot. You must return list[Order].
  • Spreads and depths determine whether a market-making strategy is profitable (wide spread + thin book = easy money; tight spread + thick book = razor edge).

Time budget

1 week (~10 hours). Finish all 5 exercises. Ship a working order_book.py class.
