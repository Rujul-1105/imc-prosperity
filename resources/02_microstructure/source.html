Module 02 — Sources (for revision)

Just citations. Read explain.html first; consult these for revision or deeper second pass.

← module README

Reading order: explain.html first, until you can answer the self-test without re-reading. Then this file for citation, then the source book chapters only if you want a second-pass deep read.

Main source

  • Larry Harris, Trading and Exchanges: Market Microstructure for Practitioners, Oxford University Press 2003.
    • Ch 1 — The trading problem.
    • Ch 2 — Orders, quotes, market structure.
    • Ch 3 — The limit order book.
    • Ch 4–5 — Dealers and auction markets.
    • Ch 6 — Market makers and specialist markets.
    • Ch 7 — Information, quotes, and trading (adverse selection).
    • Ch 12–14 — Matching engines, trade reporting, transaction costs.
  • Where to get: OUP print ~$80; or USC faculty page (Harris posts chapters as free PDFs — Google "Larry Harris Trading and Exchanges market microstructure book chapters PDF" if the link moves).

Supplement

  • BIS Working Paper, "Order flow and the bid-ask spread in modern markets" (search on bis.org). Short, math-light, modern. Skim in 30 minutes.
  • jmerle/imc-prosperity-3 — code reference for TradingState, datamodel, order book parsing.

What this module does NOT cover

  • Queue priority variants (pro-rata, FIFO) — module 17.
  • Glosten–Milgrom adverse selection model — module 17.
  • Latency and HFT microstructure — module 17.
  • Continuous double auctions (Kyle, Cont) — module 18.

For revision only

If you want a second-pass deep read after explain.html:

  • Skim Harris Ch 1–3 in 1 hour for vocabulary reinforcement.
  • Read Harris Ch 7 (adverse selection) carefully — it's the conceptual foundation for the realized-spread / effective-spread framework.
  • Read Harris Ch 12 if you want to understand matching engines in detail.

You do not need to read all of Harris. The chapters above are the only ones that matter for this module.
