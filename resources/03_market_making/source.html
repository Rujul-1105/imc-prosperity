Module 03 — Sources (for revision)

Just citations. Read explain.html first; consult these for revision or deeper second pass.

← module README

Reading order: explain.html first, until you can answer the self-test. Then this file for citation; consult the source book chapters only for revision or a deeper second pass.

Main source #1 — the math

  • Avellaneda & Stoikov (2008), "High-frequency trading in a limit order book," Quantitative Finance 8(3), 217–224. arXiv:1708.04928.
    • §2.1 — Problem setup and order arrival model.
    • §2.2 — The HJB equation.
    • §2.3 — The solution: reservation price and optimal spread (equations 3 and 5).
  • Reference code: astraflow/avellaneda-stoikov (C++ + Python).

Main source #2 — the practice (Wall-Mid)

  • TimoDiehm/imc-prosperity-3 — 2nd place P3. round_1_strategy.py is the Wall-Mid implementation. ~50 lines.

Supplement

  • Larry Harris, Trading and Exchanges Ch 6 — "Market Makers and Specialist Markets." Institutional context.
  • Cartea–Jaimungal–Penã, Algorithmic Trading (2015) Ch 1, 2 — Mathematical treatment; multi-asset, market-impact variants. (Module 18 builds on this.)
  • jmerle/imc-prosperity-3 — hybrid framework; the MarketMakingStrategy base class is a clean abstraction to mirror.

What this module does NOT cover

  • Multi-asset market making — module 18.
  • Market-impact adjustment — module 18.
  • Stochastic control / full HJB derivation — module 18.
  • Adverse-selection microprice adjustment — module 17.
  • Pro-rata vs FIFO exchanges — module 17.

For revision only

If you want a second-pass deep read after explain.html:

  • Read Avellaneda–Stoikov §2.1–2.3 carefully (3–4 hours). The math is in the paper; explain.html gave you the result; the paper gives you the derivation.
  • Trace Timo's round_1_strategy.py line-by-line to understand Wall-Mid implementation details.
  • Skim Cartea–Jaimungal–Penã Ch 1 for the general HJB framework.

You do not need to read the entire paper or book. The above is sufficient for a second pass.
