Module 03 — Sources

Two main sources: the Avellaneda–Stoikov paper (the math) and Timo's repo (the practice).

← module README

Main source #1 — the math

Avellaneda & Stoikov (2008), "High-frequency trading in a limit order book," Quantitative Finance 8(3), 217-224. arXiv:1708.04928.

The standard market-making paper. Read §2.1–2.3 carefully. Focus on equations (3) (reservation price) and (5) (optimal spread). Skip the rest on first read; revisit when you have specific questions.

Where to get it:

  • arXiv:1708.04928 — free PDF.
  • Published version behind a paywall, but the arXiv version is essentially identical.

Reference code: astraflow/avellaneda-stoikov on GitHub. C++ and Python. Faithful to the paper.

Main source #2 — the practice

Timo Diehm, imc-prosperity-3, 2nd place in P3.

The "Wall-Mid" strategy and the practical implementation of market-making. Read round_1_strategy.py in full. The functions are < 50 lines each.

Use this repo as a starting point, not a finished strategy. The team should re-implement in your own code, parameterizing on round constants.

Supplement 1 — Cartea–Jaimungal–Penã

Álvaro Cartea, Sebastian Jaimungal, Jorge Penã, Algorithmic Trading (Cambridge, 2015). Ch 1, 2.

Mathematical treatment. Builds on Avellaneda–Stoikov with multiple assets, market impact, and risk-aversion variants. Use this for module 18 (advanced) — not for the first read.

Supplement 2 — Harris, chapter 6

Larry Harris, Trading and Exchanges (2003), Ch 6 — "Market Makers and Specialist Markets."

Background on what market-makers do and how they're compensated. Less mathematical than AS, more institutional context.

What this module does NOT cover (and where to look)

  • Multi-asset market-making — module 18 (advanced).
  • Market-impact adjustment — module 18.
  • Stochastic control / HJB derivation — module 18.
  • Adverse-selection microprice adjustment — module 17 (advanced microstructure).
  • Pro-rata vs FIFO exchanges — module 17.

Reading time budget

  • Avellaneda–Stoikov §2.1–2.3: 4 hours.
  • Timo's round_1_strategy.py: 2 hours.
  • Cartea–Jaimungal–Penã Ch 1: 4 hours (skim, don't read cover-to-cover).
  • Harris Ch 6: 1 hour.
  • Total: ~11 hours. Spread over 2 weeks.

Once you've read these, move to extract.html for the formulas and code.
