Module 03 — Exercises

Five hands-on exercises. Use code/ as your starting point. Run on P3/P4 data from ../prosperity-4/data_capsule/.

← module README · extract

All exercises use the P3/P4 CSVs you have. If you don't have them yet, jmerle's repo has them.

Exercise 1 — Estimate the parameters easy · 1 hour

For P3 R1 RAINFOREST_RESIN data (day -1):

  1. Compute $\sigma$ from the rolling realized vol over the past 50 ticks. Plot the time series.
  2. Estimate $\kappa$ from the historical fill rate of touch orders. (You don't have your own touch orders, so estimate by counting the number of times the spread was $\le 2$ ticks — a rough proxy for "touch-like activity".)
  3. Pick a $\gamma$ by intuition: start with 0.1. We'll tune in Exercise 4.

Verify: $\sigma$ should be small (RAINFOREST_RESIN is FFV). $\kappa$ should be in the 0.5–5 range. $\gamma$ in 0.01–1.

Exercise 2 — AS quotes on historical mid 1.5 hours

For each tick of P3 R1 day -1, compute the AS bid and ask. Use the parameters from Exercise 1, and assume you start with 0 inventory.

Plot the bid/ask over time, overlaid on the historical mid. Verify the bid and ask are always on the correct side of the mid.

Verify: the spread (ask − bid) should be roughly constant if $\sigma$ is constant, varying with $\sigma$ when vol changes.

Exercise 3 — Wall-Mid from scratch 1.5 hours

Implement Wall-Mid in code/wall_mid.py (we provide a skeleton). Apply to P3 R1 day -1.

Plot the bid/ask from Wall-Mid overlaid on the historical mid. Compare to the AS quotes from Exercise 2.

Question: which is tighter? Which moves with the book more? Which is more stable?

Exercise 4 — Tune $\gamma$ by Sharpe 3 hours

For each value of $\gamma \in \{0.001, 0.01, 0.05, 0.1, 0.5, 1, 5\}$:

  1. Run the AS market-maker on P3 R1 day -1 with that $\gamma$.
  2. Record: total PnL, spread capture, inventory variance, max drawdown.
  3. Compute Sharpe ratio (mean PnL per tick / std PnL per tick).

Plot Sharpe vs $\gamma$. The peak is your round-specific optimal $\gamma$.

Question: is the peak at $\gamma = 0.01$ (loose) or $\gamma = 1$ (tight)? What does that say about the round?

Exercise 5 — PnL decomposition and the Wall-Mid vs AS comparison 3 hours

Using the simple backtester in code/backtest_mm.py:

  1. Run Wall-Mid on P3 R1 day -1. Decompose PnL into spread / inventory drift / rebalance cost.
  2. Run AS (with optimal $\gamma$ from Exercise 4) on the same data. Decompose.
  3. Compare. Which has higher spread capture? Lower inventory drift? Higher total PnL?
  4. Implement the hybrid (Wall-Mid center + AS skew) and re-run. Compare to both.

Verify: the hybrid should be at least as good as the better of the two on at least one metric. (Often the hybrid wins on both.)
