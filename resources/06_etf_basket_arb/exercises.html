Module 06 — Exercises

Five hands-on exercises. Use the code in code/ as your starting point.

← module README · extract

All exercises use P3/P4 basket data. GIFT_BASKET, PICNIC_BASKET, and PEBBLE are in ../prosperity-4/data_capsule/.

Exercise 1 — Solve for the basket weights easy · 1 hour

Use code/solve_weights.py on P3 R3 GIFT_BASKET data (day -1):

  1. Extract basket mid prices and leg mid prices per tick.
  2. Run OLS to recover the weights.
  3. Verify the recovered weights are close to (4, 6, 1) — the spec values.

Verify: recovered weights within ±0.1 of the spec.

Exercise 2 — Compute the spread 30 min

Use the recovered weights to compute the spread every tick:

spread = basket_mid − (4 × choc_mid + 6 × straw_mid + 1 × rose_mid)

Plot the spread time series. Plot a histogram of the spread values.

Question: what's the mean spread? The std? Is it mean-reverting (run the AR(1) test from module 04)?

Exercise 3 — The basket-arb backtest 1.5 hours

Use code/basket_arb.py on P3 R3 GIFT_BASKET data (day 0). Threshold = 10, max basket position = 5.

Backtest the strategy. Decompose PnL into spread capture (the gap you closed) and inventory drift (PnL from holding while the spread was open).

Verify: spread capture is positive. Inventory drift is small (cap holds).

Exercise 4 — Threshold sweep 1 hour

For threshold $\tau \in \{2, 5, 10, 20, 50, 100\}$, run the basket-arb backtest and record:

  • Total PnL
  • Number of trades
  • Sharpe ratio
  • Average PnL per trade

Plot each metric vs $\tau$. Find the optimal $\tau$.

Question: is the optimal $\tau$ the same as 2× the typical basket spread? (If not, your spread assumption is wrong.)

Exercise 5 — Inner rebalancing on PEBBLE 3 hours

For P4 PEBBLE data (if available; otherwise simulate 5 assets constrained to sum to 50,000):

  1. Confirm the constraint holds: do the 5 assets actually sum to 50,000 ± a small tolerance?
  2. Compute the "fair" weights from the data (equal-weight baseline: 10,000 each).
  3. Implement the inner rebalance trade: for each asset, compute its deviation from fair. Sell the rich ones, buy the cheap ones.
  4. Backtest. Decompose PnL.

Question: is the inner rebalance trade PnL? Is it zero-risk (no directional exposure)?
