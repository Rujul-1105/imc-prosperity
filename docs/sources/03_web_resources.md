# Web Resources

Online courses, tutorials, and reference material. Free unless marked.

---

## QuantConnect — Learning Center

- **URL**: https://www.quantconnect.com/learn
- **Why**: Free Python-based algorithmic trading platform with a great docs section. Best place to learn order book / microstructure mechanics in code.
- **Used in**: Module 02 (microstructure), Module 15 (Python toolkit).
- **What to read**: the "Tick Data" and "Order Book" sections.

## QuantInsti — Quantra free courses

- **URL**: https://quantra.quantinsti.com/
- **Why**: Free courses on Python for trading, options, ML. Specifically built for trading interviews.
- **Used in**: Modules 02, 04, 07.

## MIT OpenCourseWare

- **18.S096** (Lo) — Topics in Mathematics with Applications in Finance. Free, full lectures.
  - **Used in**: Module 18 (stochastic control, advanced).
- **18.636** — Mathematical Methods in Finance. Free.
  - **Used in**: Module 18 (advanced).

## Interactive Brokers — TWS API documentation

- **URL**: https://interactivebrokers.github.io/tws-api/
- **Why**: Real-world market data and order types. Useful for understanding the difference between a limit order, a stop order, etc. Not used in Prosperity (offline sandbox) but informs vocabulary.
- **Used in**: Module 02 (vocabulary).

## V-Lab (NYU Stern) — GARCH tutorials

- **URL**: https://vlab.stern.nyu.edu/
- **Why**: Free GARCH volatility models. Reference for module 10.
- **Used in**: Module 10.

## py_vollib documentation

- **URL**: https://github.com/vollib/py_vollib
- **Why**: The standard Python options pricing library. Black-Scholes, Greeks, IV smile fitting.
- **Used in**: Module 07.

## arch package documentation

- **URL**: https://arch.readthedocs.io/
- **Why**: Python GARCH library. Reference for module 10.

## Optiver — Market Making University Challenge writeups

- **URL**: optiver.com → search "university challenge"
- **Why**: Public writeups from Optiver's market-making challenge (different from IMC's but similar concepts). Good for inspiration.
- **Used in**: Module 03.

## Jane Street Tech Blog

- **URL**: https://blog.janestreet.com/
- **Why**: Monthly puzzles. Real-world trading math problems.
- **Used in**: Module 19 (manual rounds).

## QuantNet forums

- **URL**: https://quantnet.com/
- **Why**: Active forum for quant interview prep and competition discussion. Search "IMC Prosperity 4" for top-team post-mortems.

## Reddit — r/IMC, r/algotrading, r/csMajors

- **URL**: reddit.com
- **Why**: Threads about each round drop within hours. Search for "Prosperity 4" / "Prosperity 5".

## Stack Exchange — Quantitative Finance

- **URL**: https://quant.stackexchange.com/
- **Why**: Q&A for specific finance math questions. The answer to "why does my IV smile fit give negative vega?" is here.
